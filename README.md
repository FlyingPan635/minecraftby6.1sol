# MagiC 方块世界

从零实现的本地单人 Minecraft 玩法复刻。所有像素材质、物品、生物和音效由代码生成，没有使用原版程序或资源包。使用 Three.js、WebGL 2 和原生 JavaScript。

## 运行

当前已构建的游戏：运行 `start-game.cmd`，然后在桌面 Chrome 或 Edge 打开 **http://127.0.0.1:4173/**。保持服务器窗口打开。只需安装 Node.js，运行构建版本无需联网。

开发：`npm install`，`npm run dev`，打开 http://localhost:5173/。

验证：`npm test`。生成发布构建：`npm run build`。

物品栏：左键拾取或放置一组；右键分半或放一个；Shift 快速转移。配方书点击可填入真实合成格，再点击输出格取出结果。随身是 2×2，右键工作台是 3×3。熔炉输入、燃料与输出各一格，持续消耗燃料并熔炼。右键箱子保存物品。

## 生存

采集原木 → 木板 → 工作台和木棍 → 木镐 → 圆石 → 石镐和熔炉 → 铁矿熔炼 → 铁镐 → 钻石。镐决定能否采集矿物，工具会损耗。动物提供肉和羊毛；肉可熔炉烹饪。合成床并在晚上使用可以跳过夜晚、设置出生点。僵尸、苦力怕和骷髅在夜间出现；苦力怕爆炸会破坏地形，骷髅射出的箭有轨迹和方块碰撞。

锄头右键草方块 / 泥土可以耕地，种子右键耕地播种。小麦在白天逐渐成熟，附近有水时生长更快；收获成熟小麦得到小麦和种子，用 3 个小麦合成面包。树叶有概率掉落树苗，种在泥土上会长成橡树。木门由 6 块木板合成，右键开关，碰撞遵循门板厚度。人物会自动跨上半格以内的台阶，也能走出耕地。

## 世界与光影

确定性种子、无限区块加载、平原、森林、沙漠、雪地、山地、河流、洞穴、矿脉、树木、花草与村落。创建世界时可选择默认、放大化和浮空群岛。村落包含工作台、熔炉、箱子、床、井与庭园。

自动昼夜循环默认一昼夜 20 分钟。选项可调整流速、渲染距离、鼠标灵敏度、视野和动态阴影。光影包括方块顶点遮蔽、柔和太阳阴影、昼夜天空与雾、夕阳、星星、月亮、漂移云、水面波纹与反射、火把点光和雨天。水桶放出的水会下落并传播，水接触熔岩会形成黑曜石。沙子与砂砾会坠落。

## 保存与指令

每 30 秒自动保存；菜单可以手动保存。刷新之后在标题选择“继续上次的世界”。保存世界种子、方块修改、位置、模式、时间、背包、工具耐久、容器、生物、水流和掉落物。数据保存在当前浏览器及当前地址的 localStorage，换浏览器或端口有独立存档。创建新的世界会在下一次保存时替换此地址的单个存档。

常用指令：`/time set day`、`/time set night`、`/weather rain`、`/weather clear`、`/timespeed 10`、`/gamemode creative`、`/gamemode survival`、`/give log 64`、`/give 113 1`、`/tp 56 33 -23`、`/summon skeleton`、`/seed`、`/gamerule keepInventory true`、`/gamerule doDaylightCycle false`。

内置预览浏览器可能限制鼠标锁定，此时按住画面拖动视角。普通桌面 Chrome / Edge 可以点击画面锁定鼠标，Esc 释放。首次点击后音效启用。

## 实现范围

这是一次从零编写、可实际游玩的独立复刻，并非官方 Minecraft，也没有实现原版全部内容。未覆盖多人、下界与末地、红石电路、全套物品与生物、原版世界生成算法或原版资源。这些限制不影响已实现的采集、合成、探索、建造与生存循环。水流采用限定活动范围的近似模拟；部分功能方块用简化几何。可见远方范围由区块渲染距离决定。

操作与核心生存流程参考 [Minecraft 官方操作说明](https://www.minecraft.net/article/minecraft-controls) 与 [官方新手指南](https://www.minecraft.net/en-us/article/how-minecraft)。渲染接口参考 [Three.js 官方文档](https://threejs.org/docs/)。
