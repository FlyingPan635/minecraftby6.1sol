# Integration contracts

Use ES modules and Three.js from `three`. Source goes in `src/`. Desktop-first Chinese UI. Pixel textures must be original procedural textures. World geometry coordinates: block x,y,z occupies [x,x+1],[y,y+1],[z,z+1]. Player position is feet; width .6, standing height1.8, eye1.62. Sea level22. Chunk16, height96. Deterministic seed default 241108.

IDs: AIR0 GRASS1 DIRT2 STONE3 SAND4 WATER5 LOG6 LEAVES7 PLANKS8 COBBLE9 GLASS10 BRICKS11 BEDROCK12 COAL_ORE13 IRON_ORE14 GOLD_ORE15 DIAMOND_ORE16 SNOW17 CACTUS18 CRAFTING19 FURNACE20 TORCH21 WOOL22 FLOWER23 TALL_GRASS24 GRAVEL25 OBSIDIAN26 LAVA27 CHEST28 BED29. Item-only IDs: STICK100 COAL101 IRON102 GOLD103 DIAMOND104 APPLE105 RAW_MEAT106 COOKED_MEAT107 WOOD_PICK110 STONE_PICK111 IRON_PICK112 DIAMOND_PICK113 WOOD_AXE114 STONE_AXE115 IRON_AXE116 WOOD_SWORD117 STONE_SWORD118 IRON_SWORD119 BREAD120 WHEAT121 SEEDS122 BUCKET123 WATER_BUCKET124. Blocks exports B object with names above, BLOCKS dictionary with {id,name,color,solid,transparent,hardness,drop,tool?,tile?}, ITEMS item dictionary (all blocks+items), isSolid(id), isTransparent(id), getItem(id). textures exports createAtlas() => {texture,canvas,tiles, tileSize, size}; tiles map tile name or block id to [column,row]. Also exports drawItemIcon(id,canvas) or itemIcon(id) returning URL. Root uses itemIcon for held items.

World: constructor World(scene,{seed=241108,type='normal',renderDistance=4,onProgress?}). properties seed,type,renderDistance,chunks(Map),group(THREE.Group), materials. getBlock(x,y,z) numeric; setBlock(x,y,z,id) bool marks mesh dirty; getHeight(x,z) surface y of top solid +1; getBiome(x,z) Chinese string. update(px,pz,dt) handles chunks and dirty mesh; async init(px=0,pz=0) builds starting chunks, enough for spawn. findSpawn() => {x,y,z}. saveEdits()=>JSON-compatible list; loadEdits(edits); dispose(); setRenderDistance(n); raycast(origin,direction,maxDistance=5)=>{x,y,z,id,normal:{x,y,z},distance} or null. getBlock must never generate chunks just to query far away; loaded chunks only (below0 BEDROCK above height AIR). Exports CHUNK_SIZE, WORLD_HEIGHT, SEA_LEVEL. terrain pure exports for tests. type normal/amplified/floating. Shader water time accessible via material.userData or update(). Infinite world streaming.

Inventory: constructor Inventory(mode='survival'); slots array length36 each null or {id,count,durability?}, selected0..8; mode; add(id,count)=>remaining; remove(id,count)=>bool; count(id); consumeSelected(n=1)=>bool; selectedItem getter; setSelected(n); serialize() JSON; load(data); damageTool(amount=1). Recipe exports RECIPES with {id,name,result:{id,count},ingredients:[{id,count}],station:'hand'|'crafting'|'furnace'}; craft(recipeId,inventory,station='hand') => bool. Allow hand log->planks, planks->sticks/crafting, tools require table, smelting requires furnace+fuel. Can UI implement simplified recipe book alongside actual grid. Survival starts empty except optional apple2; creative hotbar building blocks.

UI constructor UI(inventory,callbacks). callbacks: start({seed,type,mode,renderDistance}), resume(), save(), exit(), settings({fov,sensitivity,renderDistance,shadows,autoTime,timeSpeed,volume}), command(text), respawn(), inventoryChanged(), craft(recipeId,station), useRecipe(recipeId,station). Expose setScreen('title'|'loading'|'pause'|'inventory'|'settings'|'death'|null), showInventory(station='hand',chest? optional), update(state), toast(text), setLoading(progress,text), isOpen (getter), currentScreen. state fields {health,hunger,air,xp,selected,mode,itemName,targetName,biome,time,day,fps,position:{x,y,z},flying,debug,saveAvailable}. Interface only needs supported callbacks. Root handles keyboard E/Escape and calls UI methods. HUD hotbar, pixel hearts/hunger/air, crosshair, selected item name, block breaking overlay optional; title game menu background transparent over scene, game-native options. F3 debug optional. T command input UI callbacks. Add class hide HUD for screens. UI's inventory clicks call inventoryChanged.

Entities: constructor EntityManager(scene,world,{onDamage(amount,source),onDrop(id,count,pos),sound?}); spawnAround(pos,count=10); update(dt,player,{daylight,time,mode,paused}); attack(origin,direction,range=3.2,damage=3) => hit info or null; serialize(); load(data); dispose(); entities array. Player object {position:Vector3,health,velocity?,grounded?}. manager animal sheep/pig/cow, hostile zombie/creeper with simple collision/path chase. onDrop pass world coordinates. Creature pixel original textures generated canvas or simple color boxes, recognizable body/head/limbs, limb animation and shadow. Mob targeting should not hit behind opaque blocks (limit range root passes). May add drops managed root. Sound class export SoundSystem with start(), setVolume(v), play(name,variant?), update(dt,state), dispose(), procedural WebAudio no files. Footsteps/break/place/hurt/jump/water/swing etc.

Ownership: world agent blocks.js textures.js terrain.js world.js; UI agent inventory.js ui.js ui.css; entity agent entities.js sound.js. Root all other files. Do not edit others' files; report extra contract changes.
